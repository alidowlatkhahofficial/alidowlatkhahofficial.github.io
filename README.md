# وب‌سایت آهنگ‌های علی دولت‌خواه — نسخه‌ی GitHub Pages

سایت استاتیک، بدون هیچ وابستگی به گوگل. بدون فیلترشکن هم باز می‌شود
(به شرطی که گیت‌هاب از اینترنت شما باز شود).

## فایل‌ها
- `index.html` — کل سایت: طرح تیره و طلایی، هیرو با عکس خواننده، کارت «اثر ویژه»،
  فهرست آهنگ‌ها با جستجو، و پلیر پایین صفحه (پخش/توقف، قبلی/بعدی، نوار پیشرفت، صدا).
- `portrait.png` — عکس خواننده در هیرو.
- `songs/test.mp3` — آهنگ تست (نمونه‌ی عمومی). وقتی آهنگ واقعی آمد، این فایل و ردیفش را حذف کنید.

## اضافه کردن آهنگ جدید
۱. فایل MP3 را در پوشه‌ی `songs` بگذارید، مثلاً `songs/song2.mp3`
۲. در `index.html`، در فهرست `SONGS` یک خط اضافه کنید:
   `{ title: "نام آهنگ", artist: "علی دولت‌خواه", file: "songs/song2.mp3", cover: "" },`
   اگر کاور دارد، به‌جای `""` آدرس عکس را بنویسید.
۳. تغییرات را Commit و Push کنید؛ سایت GitHub Pages خودکار به‌روز می‌شود.

## انتشار در GitHub Pages
۱. در گیت‌هاب یک ریپوی Public بسازید، مثلاً `ali-dowlatkhah-music`
۲. همه‌ی فایل‌های همین پوشه را در ریپو آپلود کنید (ریشه‌ی ریپو، نه در زیرپوشه).
۳. در ریپو بروید به Settings ← Pages ← Source: Deploy from a branch،
   Branch: main، Folder: / (root) — و Save کنید.
۴. آدرس سایت می‌شود: `https://<username>.github.io/ali-dowlatkhah-music/`

## نکته‌ها
- هیچ درخواستی به گوگل، شیت یا درایو نمی‌رود؛ همه‌چیز همین‌جاست.
- وقتی فهرست `SONGS` خالی باشد، قسمت آهنگ‌ها خالی می‌ماند و هیچ متن «به‌زودی» نشان داده نمی‌شود.
- هر فایل MP3 باید زیر ۱۰۰ مگابایت باشد.
